MG1 Tracker 3.0 – PWA pro iPhone

1. Rozbal ZIP.
2. Nahraj soubory index.html, manifest.json, service-worker.js a složku icons do kořene veřejného GitHub repozitáře.
3. GitHub Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Na iPhonu otevři publikovanou HTTPS adresu v Safari > Sdílet > Přidat na plochu.

Data jsou jen lokálně v prohlížeči. V části Více lze exportovat/importovat zálohu JSON.
Pozor: před nahrazením staré verze exportuj její data. Verze 3 má nové datové schéma a staré záznamy nepřevádí automaticky.
